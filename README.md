A fully responsive landing page for an AI-powered meal planning service featuring interactive sliders, smooth animations, and modern UI components.

🌐 Live Demo: https://obielousov.github.io/AiChefMate-/

## Features

- **Interactive hero section** — engaging layout with call-to-action elements and animated statistics
- **Dual synchronized sliders** — Swiper-powered content and card sliders synchronized via the Controller API
- **Scroll reveal animations** — sections fade in using IntersectionObserver
- **Responsive navigation** — sticky header with a mobile burger menu
- **Interactive pricing switcher** — active plan selection with dynamic UI states
- **FAQ accordion** — smooth expand/collapse animations
- **Accessibility** — semantic HTML, keyboard-friendly navigation, `:focus-visible`, and ARIA attributes

## Tech Stack

- **HTML5** — semantic markup and SEO-friendly metadata
- **SCSS** — variables, mixins, partials, and modular architecture compiled into minified CSS
- **Vanilla JavaScript** — framework-free implementation with Swiper integration
- **Swiper 12** — synchronized sliders and touch interactions
- **Assets** — Google Fonts (Work Sans & Syne), SVG icons, and optimized images

## Project Structure

```
.
```

## Run Locally

Clone the repository:

```bash
git clone https://github.com/obielousov/AIChefMate.git
```

Open `index.html` in any modern browser.

No installation or build process is required.
